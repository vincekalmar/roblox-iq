# Roblox Audio Workflow

## Direction

Build a reusable categorized library of sounds the project is allowed to use. Prefer layering/recombining known sounds before generating or uploading a one-off asset.

Useful categories may include:
- UI
- whoosh/motion
- impact
- success/reward
- mental/psychic
- technology/mechanical
- construction
- environment

## Workflow

1. Identify the gameplay beat and importance level.
2. Reuse approved sounds/recipes first.
3. Layer only when layers have distinct jobs.
4. Test against music, VFX, UI, and repeated use.
5. Prevent frequent actions from becoming exhausting.
6. Record successful recipes in the library notes.

Do not commit audio files or licenses the project is not allowed to redistribute.

See `docs/art/AUDIO-STYLE.md` and `automation/audio/README.md`.
