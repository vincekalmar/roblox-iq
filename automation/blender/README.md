# Blender Automation — Scaffold

Potential deterministic helpers once Blender is part of the active pipeline:
- import/generated-mesh cleanup
- triangle/face reporting
- decimation to configured budgets
- texture baking
- multi-angle review renders
- pivot/origin normalization
- scale/export presets for Roblox

Do not run destructive Blender automation on an irreplaceable source file without a checkpoint/copy.
