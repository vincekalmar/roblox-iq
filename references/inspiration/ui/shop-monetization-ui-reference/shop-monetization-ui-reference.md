# Shop / Monetization UI Reference

## Reference purpose

This screenshot is a strong reference for:

1. Roblox IQ's general UI visual language.
2. How optional Robux purchases can be presented clearly without making the entire game feel like a storefront.
3. How shop categories, product cards, icons, and HUD purchase entry points can be organized.

The goal is not to copy this shop exactly.

The useful parts are:
- chunky Roblox-style UI
- strong product cards
- very readable purchase buttons
- custom icons
- category navigation
- contextual Robux purchase entry points
- clear separation between normal gameplay HUD and monetization UI

---

# Visual style

This continues the visual direction established by the Concept Index reference.

Important traits:

- studded UI surfaces
- bright saturated colors
- thick black borders
- strong white text with dark outlines
- large custom icons
- obvious button depth
- simple panel hierarchy
- very clear clickable areas
- minimal ambiguity about what each button does

The UI feels deliberately Roblox-like rather than like a generic web or mobile application.

This is a strong style reference for Roblox IQ.
