# Concept Index UI Reference

## Reference purpose

This screenshot is a strong reference for both:

1. Roblox IQ's UI visual language.
2. A possible Concept Index / collection system.

The goal is not to reproduce this interface exactly. The useful parts are its Roblox-style presentation, iconography, collection anticipation, rarity presentation, and readable progression.

---

## What I like visually

### Strong Roblox identity

The interface feels intentionally Roblox-like rather than like a generic mobile-game UI.

Important traits:

- visible stud textures across many surfaces
- chunky rectangular panels
- thick dark borders
- strong white text with black outlines
- bright colors
- obvious depth/shadows on buttons and panels
- simple but polished composition
- high contrast between content and background
- easily clickable buttons, everything can be hit by a thumb on a phone

Roblox IQ should explore a similar level of strong Roblox identity.

This fits the broader game art direction where studs and classic Roblox visual language are used intentionally.

- stylized money icon
