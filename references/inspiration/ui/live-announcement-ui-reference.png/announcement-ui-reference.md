# Live Announcement UI Reference

## Reference purpose

This screenshot is a strong reference for Roblox IQ's **live-event announcement system**.

The key thing being studied is not the entire HUD.

The important parts are:

- large center-screen announcements
- highlighted words based on rarity or importance
- event-style messaging that makes the whole server notice something exciting
- reset/global-event messaging
- urgency and spectacle without opening a menu

This is a strong reference for:
1. rare Concept spawn announcements
2. area-specific event announcements
3. Concept Reset announcements
4. future server-wide excitement / dopamine moments
