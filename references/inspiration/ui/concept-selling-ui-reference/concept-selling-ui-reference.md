# Concept Selling UI Reference

## Reference purpose

This screenshot is a strong reference for Roblox IQ's Concept inventory and selling flow.

The main ideas being studied are:

- selling unwanted collected items for money
- sorting inventory by useful properties
- selecting multiple items at once
- showing total sale value before confirming
- clear separation between inventory categories
- chunky Roblox-style UI consistent with the other references

The goal is not to copy the exact pet-selling interface.
