# Apple Orchard Design Reference

## Purpose

These images are inspiration for the visual design of the Apple Orchard / starting area.

They are not a source of truth for gameplay, layout, progression, or exact asset construction.

The purpose of this folder is to capture visual ideas we currently like while designing the starting area.

As the project's visual direction becomes more established, successful ideas from these references can later be promoted into approved references or permanent visual-style rules.

## Apple Tree 1.png

This image shows one angle of the current candidate direction for the Apple Orchard tree.

What I like:
- very Roblox-like construction
- visible studs
- chunky trunk
- large blocky canopy
- simple geometry
- strong readable silhouette
- stylized rather than realistic

This is not meant to be copied exactly.

Use it as inspiration when designing the first Apple Orchard tree.

## Apple Tree 2.png

This image shows another angle of the same general tree design.

Use it together with `Apple Tree 1.png` to better understand:
- canopy construction
- trunk proportions
- how the blocky shapes overlap
- how the tree reads from multiple viewpoints

The goal is to eventually create one strong Apple Orchard tree style and then derive related variants from it.

## Shrubbery.png

This image is inspiration for the smaller greenery used around the Apple Orchard.

What I like:
- simple blocky shrubs
- Roblox-native appearance
- small decorative greenery that works with the studded environment
- enough detail to make the area feel planted without becoming realistic

Potential uses:
- around orchard trees
- near paths
- around the edges of the orchard
- as small environmental accents

Do not interpret this as a requirement to fill all empty grass with shrubs.

## Grass.png

This image is inspiration for the Apple Orchard ground treatment.

What I like:
- grass represented through Roblox-style geometry and surface treatment
- visible studs
- stylized green ground rather than realistic terrain
- possible patterned / checkered variation if it looks good in the final environment

Use this when experimenting with the ground language of the starting area.

The exact grass treatment is still open.

## Overall direction

The common visual qualities across these references are:

- strongly Roblox-native
- visible studs
- chunky/simple geometry
- stylized rather than realistic
- readable at normal gameplay distance
- appropriate for a bright Apple Orchard starting area

Do not copy the original game's layout or gameplay structure.

These references are for visual inspiration only.
