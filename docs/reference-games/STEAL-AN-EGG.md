# Steal an Egg — Reference Notes

This is primarily a **mechanical/readability reference**, not an art-direction reference and not a request to clone the game.

## Why it matters to Roblox IQ

The useful pattern is the relationship between shared-world activity and a nearby personal progression base.

For Roblox IQ, the analogous rhythm is:

```text
area / object activity
→ return to plot
→ improve the main progression station / base
→ become more capable
→ access stronger content
```

## Patterns worth borrowing

### Authored plot progression

Prefer predetermined purchase/build locations over unrestricted free building.

This lets upgrades create strong controlled visual changes and keeps the plot understandable.

### One obvious main progression station

Roblox IQ's study station should act as the visually obvious primary plot progression object.

The thematic implementation is different: desk/book → study/chess → PC → advanced intelligence/research technology.

### Visible social progress

A more advanced plot should look more advanced from outside it. This supports comparison and aspiration without requiring direct PvP.

### Compact shared-world ↔ plot loop

The player should not need a long commute between the world activity and their upgrade base, especially early in the game.

### Gradual reduction of traversal friction

The reference highlights why movement quality matters in a repetitive loop. Roblox IQ should solve this in-theme through better technology, shortcuts, or comprehension rather than copying another game's exact movement system.

## What not to copy

- egg theme/content
- exact economy
- exact station/treadmill implementation
- exact map layout
- exact UI/art identity
- exact upgrade costs/curves

## Design lesson

Borrow the **readability of the loop**, not the surface content.

When considering a reference-game mechanic, document what player problem it solves before implementing an analogous system.
