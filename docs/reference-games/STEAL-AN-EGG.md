# Steal an Egg — Reference Notes

## Role of this reference

Steal an Egg is primarily a **mechanical/readability reference** for Roblox IQ.

It is useful because it demonstrates a compact loop between shared-world content, a personal plot, and a highly visible repeatable progression station.

It is **not** the target art style, exact economy, theme, map, or content set.

## The useful structural lesson

The pattern worth studying is roughly:

```text
interact with / obtain something in shared world
→ bring/use it at personal plot
→ primary progression station converts that into growth
→ money/progression improves the station/base
→ player becomes more efficient / reaches better content
→ repeat
```

Roblox IQ adapts that structure into:

```text
find object in area
→ visualize/comprehend it
→ use mental image at Study Station
→ train IQ
→ use money to improve Study Station / plot
→ higher IQ unlocks better objects and areas
```

## Pattern 1 — authored plot progression

The useful idea is not free building. It is that important upgrades occupy predetermined locations and visibly change when purchased.

Roblox IQ should use this for:
- Study Station
- Research Center
- later major plot structures

Why it helps:
- player knows what can be purchased
- designer controls composition
- mobile interaction is simpler
- other players can read advancement visually

## Pattern 2 — one obvious primary station

A strong progression game benefits from one object that visually communicates:

> This is where my core training gets better.

For Roblox IQ, that is the **Study Station**.

It should not remain a tiny desk forever. Its silhouette and technology level should change dramatically across progression.

## Pattern 3 — visible social progression

A player should be able to look across the server and think:

> That person's setup is way more advanced than mine.

Roblox IQ can create this through:
- Study Station tier
- Research Center presence/tier
- advanced technology/effects
- difficult mental-item displays if that system is adopted

This produces social aspiration without requiring PvP.

## Pattern 4 — compact shared world ↔ plot rhythm

Repeated progression loops become annoying if the world activity and plot are separated by long empty travel.

The starting island therefore places plots around the central orchard.

The player should be able to:
- leave plot
- reach useful orchard content quickly
- return to plot quickly

Later areas can be farther/more complex only if movement progression reduces the friction.

## Pattern 5 — purchases are physically contextual

A useful model for Roblox IQ is that routine upgrades happen where the result will exist.

Examples:
- upgrade the Study Station by interacting with the Study Station
- build the Research Center at the Research Center build location
- buy a future plot structure at its authored pad

This is preferable to walking to a generic shop for every base upgrade.

## Pattern 6 — movement progression matters

Steal an Egg is useful as a reminder that a repetitive travel loop must become easier/more satisfying as the player grows.

Roblox IQ should solve the same problem through its own fantasy:
- technology
- vehicles/devices
- IQ-gated shortcuts
- later teleport/spatial comprehension

Do not copy the exact movement system merely because it works in the reference.

## What Roblox IQ should deliberately change

### Theme

Egg collection is replaced by mental visualization/comprehension.

### Primary station

The analogous station is intellectual:

```text
book + desk
→ chess / study
→ computer
→ advanced cognition/research technology
```

### Area gating

Frame new areas as things the player cannot yet comprehend rather than generic zone prices.

### Money/IQ split

Roblox IQ has two conceptually different resources:
- IQ = capability
- money = infrastructure/support

The economy should be designed around that distinction rather than copied from the reference.

## What not to copy

- egg theme or object set
- exact treadmill implementation
- exact map geometry
- exact UI
- exact economy/prices
- exact progression curve
- monetization
- asset style
- naming
- one-to-one plot layout

## Questions to ask when using this reference

Before borrowing a mechanic, answer:

1. What problem does it solve in Steal an Egg?
2. Does Roblox IQ have the same problem?
3. Can the solution be expressed through the IQ/comprehension fantasy?
4. Can we keep the readability while creating a different identity?

## Main takeaway

Borrow the **clarity of the progression loop and plot readability**, not the surface content.
