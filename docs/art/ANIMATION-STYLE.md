# Animation Style

Status: **CURRENT DIRECTION / TO BE TRAINED FROM APPROVED EXAMPLES**

## Purpose

Animation should sell intelligence, effort, upgrades, and spectacle while remaining readable in Roblox's gameplay camera.

## Current rules

- key poses and silhouette matter more than subtle realism
- routine interactions should be short enough not to interrupt the loop
- major unlocks can use longer/cinematic motion
- preserve responsiveness; do not trap the player in long animations for frequent actions
- use exaggerated timing/pose changes when they improve readability
- test on the actual Roblox rig and camera

## Early animation needs

Likely first examples:
- visualize/concentrate pose
- Study Station interaction
- purchase/build reaction
- short success celebration
- object spin/mental manipulation presentation

The exact motion language should come from approved references and in-game tests.
