# Audio / Feedback Style

Status: **CURRENT DIRECTION / TO BE TRAINED FROM APPROVED EXAMPLES**

## Purpose

Audio should reinforce the game's escalation and make actions feel responsive without fatiguing the player during repetition.

## Current rules

- frequent actions use short/light sounds
- upgrades and unlocks get stronger layered beats
- reserve the largest low-end/impact moments for genuinely important events
- distinguish mental/comprehension sounds from construction/technology sounds
- UI sounds should be crisp and unobtrusive
- test repeated actions for annoyance, not only one-off impact

## Library direction

Build a rights-cleared categorized library with source/license notes. Prefer reusable sound recipes over unnecessary one-off uploads.
