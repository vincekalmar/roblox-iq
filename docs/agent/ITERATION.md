# Workflow Iteration Log

Use this file only for cross-discipline workflow lessons that are not better placed in `docs/LESSONS.md` or a specific skill.

## Promotion rule

A lesson should graduate into permanent workflow infrastructure when at least one is true:
- the same class of failure has happened more than once
- a deterministic check can catch it cheaply
- the failure is expensive/destructive enough to prevent proactively
- an approved result establishes a reusable quality bar

## Entry template

```text
Date:
Discipline:
Task:
Failure or success:
Root cause:
Immediate fix:
Reusable improvement:
Where encoded: skill / automation / test / reference / none
```

Keep this concise. The goal is to improve the harness, not create a diary.
