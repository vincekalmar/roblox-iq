# Progression

## Progression axes

### IQ
The primary capability stat. More IQ should let the player comprehend stronger objects and access more advanced content.

### Study station
The primary repeatable plot upgrade path and current treadmill-equivalent. It should visibly evolve from a basic desk/book into increasingly advanced study/technology setups.

### Plot/base
Authored purchases physically appear in predetermined locations. Current examples include the study station, Research Center, and item/display space.

### Areas
New environments contain stronger/different items. Access should be framed as increased comprehension rather than generic World 2 / World 3 doors whenever possible.

### Item difficulty/value
Objects should escalate from simple/familiar to larger, stranger, mutated, technological, cosmic, and eventually conceptual targets.

### Traversal
The world should become easier/cooler to navigate as progression increases, but the exact system is open. Possible directions include smarter gear, vehicles, shortcuts, or comprehension-based travel.

## Unlock philosophy

Use IQ when the fantasy is "my mind is not ready for this yet."

Use money when the fantasy is "I can now afford/build better tools or infrastructure."

Use both when a technology should require both understanding and resources.

Avoid locking content behind arbitrary currencies when IQ or money already explains the decision.

## Current escalation direction

Illustrative sequence only, not a locked content list:

```text
apple / simple fruit
→ books / chess / common objects
→ vehicles / machines
→ buildings / large structures
→ advanced technology
→ rockets / planets
→ black holes / impossible objects
→ abstract or conceptual targets
```

The point is the increasing mental absurdity, not these exact objects.

## Early-game milestones

These are design milestones, not final balance values.

| Milestone | Requirement | Reward | Purpose |
| --- | --- | --- | --- |
| First visualization | Starting capability | Apple / first mental object | Teach the fantasy and interaction |
| First training loop | First visualized item | Initial IQ gains | Teach item → IQ connection |
| First desk improvement | Early money | Better study output / visible desk upgrade | Teach plot investment |
| Research Center | Early-mid money and/or IQ | New upgrade surface/system | Establish plot expansion |
| First comprehension gate | IQ threshold | Area 2 | Prove that intelligence changes the accessible world |

## Social progression

A player's advancement should be legible from their plot where practical. Players should be able to look at another plot and recognize that its owner has progressed farther because the study/research setup is visibly more advanced.
